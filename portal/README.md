# Nexusyl Portal

React SPA for the Nexusyl authenticated portal (CRM + LMS).

**Full project documentation:** see the [root README](../README.md).

## Quick commands

```bash
# From repo root
npm run dev:portal

# Or from this directory
npm run dev        # http://localhost:5173
npm run build      # production build → dist/
npm run lint       # oxlint
```

## Environment

```bash
cp .env.example .env.local
# Set VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, VITE_MARKETING_URL
```
